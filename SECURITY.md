# Security Policy

## Supported versions

This project is pre-1.0. Only the latest commit on `master` is supported;
there are no maintained release branches.

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub Security Advisories:
use **"Report a vulnerability"** under the repository's **Security** tab.

**Do not open a public issue for a security report.** Public issues disclose
the problem before a fix exists.

Reports are handled on a best-effort basis. You will get an acknowledgement
and a fix or a documented decision as quickly as maintainer time allows.
